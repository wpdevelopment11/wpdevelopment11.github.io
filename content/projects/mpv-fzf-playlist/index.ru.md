### Переключение между медиафайлами в плейлисте mpv с помощью утилиты fzf (с поддержкой EPG в формате XMLTV)

Дает возможность использовать fzf в терминале для выбора файла для воспроизведения из плейлиста mpv. Можно указать ссылку на XMLTV файл, чтобы увидеть программу передач.
