## Текстовый редактор, реализованный с нуля с использованием HTML5 Canvas API

Текстовый редактор с пользовательским интерфейсом, построенным на основе HTML5 Canvas. Все стандартные функции текстового редактора, такие как курсор, выделение текста и полосы прокрутки, реализованы с нуля с использованием графических примитивов, предоставляемых 2D контекстом рендеринга.
